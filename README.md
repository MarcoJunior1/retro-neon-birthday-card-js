# 🎂 Aniversário da Ágatha — Retro 80s

Cartão de aniversário interativo com estética **retrô anos 80 / neon (VHS)**.

## ✨ O que tem

- Título estilo VHS e cores neon (rosa, ciano, amarelo)
- Fontes *Press Start 2P*, *Permanent Marker* e *Orbitron*
- Interação final: **sopre no microfone para apagar as velas** 🕯️ (usa `getUserMedia`, então é preciso permitir o microfone)
- Mensagem surpresa de feliz aniversário

## 🗂️ Estrutura

```
├── index.html
├── bola.png
└── civic.png
```

## 🚀 Como usar

Abra `index.html` em um navegador (de preferência via `https` ou `localhost`, para o microfone funcionar).
